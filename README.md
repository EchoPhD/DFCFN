# DFCFN
DFCFN: Dual-stage Feature Correction Fusion Network for Hyperspectral Pansharpening

The DFCFN folder contains training files, excluding datasets and training results.

Please download the datasets and their MATLAB preprocessing programs from the cloud disk：
https://pan.baidu.com/s/13p2EXv9uZJfsuBgrAm1VRg  |  1kwx

Training results are stored in the results folder.


Note: 
(1) The Chikusei dataset I used is the 72-image version. The black edge areas of the original dataset have been removed, so the total number of images is reduced from 81 to 72.

(2)The metrics in the paper are not obtained from network training results, but tested via MATLAB. Please download the metric testing code from the cloud disk link：
https://pan.baidu.com/s/1z7_RSMYjTKp4sWnYMEpYiQ  |  rwsj
